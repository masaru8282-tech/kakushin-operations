# 初心者向け：自分のPCでWeb管理画面を試す

この手順は自分のPCをテスト環境にします。Google・Slackの認証設定は不要です。本番データは変更せず、同梱の架空CSVで試せます。クラウド環境の8000番ポートはPCのブラウザーから直接表示できないため、まずPCにコードをコピーして起動します。

## 1. 必要なものを用意する

1. https://www.python.org/downloads/ からPython 3.11以上をインストールします。Windowsではインストール時に **Add python.exe to PATH** にチェックを入れます。
2. GitHubの `masaru8282-tech/kakushin-operations` を開き、ブランチが **main** になっていることを確認します。
3. 緑色の **Code** ボタン → **Download ZIP** をクリックします。非公開リポジトリの場合はアクセスできるGitHubアカウントでログインしてください。
4. ZIPを右クリックして展開します。`README.md`、`kakushin`、`examples` のあるフォルダーを開きます。

## 2. コマンドを実行する画面を開く

Windowsでは展開したフォルダーの空いている場所を右クリックし、**ターミナルで開く** を選びます。macOSではターミナルを起動し、`cd ` と入力してから展開したフォルダーをターミナルへドラッグし、Enterを押します。

以下のコマンドはWindows向けです。macOS/Linuxでは先頭の `python` を `python3` に読み替えてください。

```bash
python --version
python -m unittest discover -s tests -v
python -m kakushin serve --port 8000
```

最初のコマンドでPython 3.11以上、テストで `OK`、最後に `KAKUSHIN operator server started` が出れば起動しています。追加パッケージのインストールは不要です。起動中はターミナルを閉じないでください。

## 3. ブラウザーで表示して架空CSVを試す

1. 同じPCのChrome/Edge/Safariを開きます。
2. アドレス欄に `http://127.0.0.1:8000` と入力してEnterを押します。これは自分のPCだけに接続するアドレスです。
3. **CSV・日次集計** タブのファイル選択で、展開フォルダー内の `examples/reservations.csv` を選びます。
4. 対象月を **2026年10月**、業務日を **2026年10月22日** にします。サンプル用の日付であり、今日の日付のままにしないでください。
5. 収録範囲を **対象月・全施設の全件と確認済み** にします。この宣言は同梱の架空サンプルに対するものです。実CSVが全件か不明なときは「未確認」にします。
6. **集計・準備候補を作成** をクリックします。売上 **35,000円**、件数 **2件**、泊数 **7泊**、税 **3,800円** が期待値です。
7. **実行履歴** タブで保存された結果を確認します。同じ条件で再実行すると同じ結果を再表示します。
8. **在庫・発注計算** タブでは、計算例を選び **候補を計算** できます。ここでの結果は入力した数値に対する候補で、本番更新・実発注ではありません。

## 4. 終了・再開する

終了はターミナルで **Ctrl+C** を押します。再開時は同じフォルダーで `python -m kakushin serve --port 8000` を実行します。ローカルの実行履歴は `.runtime` フォルダーに保持されます。

## うまく動かない場合

- `python が見つからない`：Windowsでは `py -3 --version` を試し、動けば上の `python` を `py -3` に置き換えます。Python未導入なら手順1へ戻ります。
- `No module named kakushin`：コマンドを実行した場所が違います。`README.md` と `kakushin` フォルダーがある場所で実行します。
- `Address already in use`：同じアプリを別ターミナルで起動していないか確認します。他のアプリを止めずに試す場合は `--port 8001` で起動し、ブラウザーも末尾を `:8001` にします。
- ブラウザーに接続できない：サーバー起動のターミナルが開いているか、PC側で起動しているか確認します。このアドレスはクラウド側で起動したサーバーには接続しません。
- 保留が表示される：対象月、業務日、収録範囲を確認します。未知・欠損を推測で0にしない設計のため、保留自体はエラーとは限りません。

このサーバーはローカル専用です。インターネット公開、別PCからの共有、本番の複数人運用には別途認証・HTTPS等の設計が必要です。実CSV・秘密設定をGitHubへアップロードしないでください。元仕様書と実予約の取消料特例はGit対象外のため、新しいPCには含まれません。
