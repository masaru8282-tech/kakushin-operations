# 次の作業：実ファイルを画面で照合する

この機能はCSV・PL Excel・リネン管理Excelの読み取り専用照合です。Google Sheets・Slackには接続しません。入力原本・照合結果・確認条件をサーバーのディスクへ保存せず、必要な結果だけ操作者がダウンロードします。GitHubにも入力を送信しません。

## いま開いているCodespacesを更新する

1. ブラウザーでCodespacesの開発画面に戻ります。管理画面の隣のタブです。
2. 下の **ターミナル** を押し、次の1行を貼り付けてEnterを押します。

   ```bash
   git pull --ff-only && python3 .devcontainer/start_demo.py --restart
   ```

3. `KAKUSHIN ready` が出たら、既に開いている管理画面のタブを再読み込みします。
4. **ファイル照合** が最初に表示されます。ポートの公開範囲は **Private** のまま使用してください。

この再起動は同じcheckoutから起動した既知のKAKUSHINデモ／照合サーバーだけを対象にします。不明なプロセスは止めません。新しいCodespaceでは照合モードが自動起動するため、この更新コマンドは通常不要です。元のデモ機能は `--demo` で引き続き使えます。

## 3ファイルを照合する

1. **予約CSV**、**PL Excel**、**リネン管理Excel** をそれぞれ選択します。同じ更新時点のファイルを使ってください。
2. **対象月** と **使用数の照合開始日** を設定します。予約PLはCO月、リネン使用は指定日から承認済み期限（現行は2026/10/31）までを照合します。
3. 収録範囲は、確認できる場合だけ **対象月・全施設の全件と確認済み** を選びます。全件性が未確認の場合、PLの数値が一致していても確定扱いにしません。
4. 今回用の確認条件JSONが提供されていれば、任意の **確認済み条件ファイル** に指定します。CSV・2つのExcel・対象月・日付の一致を確認してから適用します。別ファイルに流用できません。
5. **3ファイルを照合** を押します。確認済み条件ファイルがない場合、取消料などは推測せず確認待ちになります。
6. 確認できた個別取消料・金額0の手動作成だけを選び、根拠と割当列を指定して **選んだ条件で再照合** を押します。八代の件数差を除外する場合も、理由を入れてこの実行に限って選択してください。
7. **照合結果JSONを保存** で結果を自分のPCへ保存できます。原本のゲスト名・電話・住所・予約IDは結果へ出力しません。

ファイル・日付・対象月を変更すると画面の確認条件を破棄します。条件ファイルを付けたまま対象を変更すると一致検証で拒否します。除外条件はルール正本・次の日次処理へ自動継承しません。

## 結果の読み方

- **PL 一致**：210セルについて一致、または明示された今回の件数差除外だけがある状態。除外セルと理由は別表示します。
- **PL 確認待ち**：全件性、未承認の個別特例・OTA、数値・構造等に未解決の問題があります。この場合のCSV合計は未確定の部分集計です。
- **リネン使用数**：次回人数・泊数が分かる品目と固定寝具を照合。次回予約がないCSVだけで「次回予約なし」とせず、タオルは判定から除外します。
- **在庫・連動・未配分**：使用数一致とは別の確認事項です。マイナスは表上の計算値であり、実物不足とは断定しません。実施日、実在庫、搬入・移動の未記録を確認してください。

## 実行環境と保護

Codespacesでは環境が提供する正確な転送ホストだけを許可します。ポートはPrivateで使用し、インターネット一般公開はしないでください。通常のローカルサーバー・架空デモとは別モードです。埋め込み表示は照合モードでは禁止し、別タブで開きます。CSRF検証・Host検証・入力サイズ制限・ZIP展開上限・外部実体XML拒否を適用します。

Python標準ライブラリだけでExcelの必要タブ・必要セルを読みます。マクロや外部リンクの実行・数式再計算は行いません。共有数式は参照位置だけを展開し、結果は書き出し時のキャッシュ値で比較します。キャッシュ未取得や見出し・合計式の違いは一致扱いにしません。Excelに日付・品目行の変更がある場合は自動的に旧番地へ合わせません。

手動起動する場合：

```bash
python3 -m kakushin serve --review --port 8000
```

これはloopback専用です。Codespacesで外部バインドする場合は `--host 0.0.0.0` を追加し、Codespaces提供のホストを使います。自前の非公開リバースプロキシを使う場合は正確な `--allowed-host` を指定します。認証はCodespacesのPrivateポートまたは運用側の認証プロキシが前提であり、このPythonサーバーを直接公開しないでください。

照合後は **次へ：3日間計画を確認** から [リネンの予定・発注案](DAILY-PLAN.md) へ進めます。同じCSV・リネンExcelを再利用し、PLや今回の会計例外と計画処理を分けます。
