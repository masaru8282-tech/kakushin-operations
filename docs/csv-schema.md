# 詳細CSVの列名辞書

実予約や個人の値を含まないスキーマ定義です。

 詳細CSV44列の辞書

以下は実際の列順。現行業務で使わない列のAirHost固有の決済・内部意味は原システム仕様未取得のため、列名だけから断定しない。個人情報列は計算に不要であり、通常の業務ログ・Slack結果へ出さない。
